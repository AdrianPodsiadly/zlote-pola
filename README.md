# 🌾 Złote Pola

Strategiczna gra ekonomiczna o prowadzeniu gospodarstwa rolnego w Polsce — w przeglądarce, na telefonie i komputerze.

Zaczynasz na małej farmie po dziadku. Planujesz sezon, zlecasz prace polowe, kupujesz maszyny i ziemię, zatrudniasz ludzi, hodujesz zwierzęta i handlujesz na rynku.

**Uruchomienie:** otwórz `index.html` w przeglądarce — nic nie trzeba instalować.
